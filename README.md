## Overview

This portfolio serves as an online representation of my work, including details about my skills, academic projects, and research. The project demonstrates my proficiency in web development using HTML, CSS, and Bootstrap.

- **Home:** Introduction and greeting with an animated name.  
- **About Me:** A brief overview of my academic background and key skills.  
- **Resume:** A detailed section about my soft and technical skills, along with my ongoing projects and research paper.
